## Project Overview

Master's thesis project on machine learning models for scattering kernels in rarefied gas dynamics. The goal is to replace physics-based collision models (Borgnakke-Larssen) with ML-trained models (MDN/BetaMDN) within DSMC simulations, while preserving physical conservation laws and matching macroscopic transport properties like viscosity.

## Environment

Python 3.14 virtual environment in `.venv/`. Activate with:
```bash
source .venv/bin/activate
```

No `requirements.txt` or `pyproject.toml` — dependencies are inferred from imports: `torch`, `numpy`, `sklearn`, `scipy`, `matplotlib`, `tqdm`, `numba`, `hyperopt`.

## Common Commands

The pipeline entrypoint `scripts/run_pipeline.py` is the preferred way to run things — it routes outputs through `paths.py`, which auto-creates `results/models/...` and `results/plots/...` on demand. The individual scripts in `experiments/`, `training/`, and `visualization/` still work and are now thin wrappers around the same reusable functions.

```bash
# Generate CTC collision dataset (Numba-accelerated, ~400k collisions)
python ctc_adjusted/ctc_h2_multiple_collisions_numba.py

# Train a single model (kind = mdn | beta_mdn)
python scripts/run_pipeline.py train --kind beta_mdn --dataset data/H2H2_collisions_numba_b1_0_400000_seed42.npy --wf 4

# Weighting-factor sweep (trains wf ∈ [0.25..7])
python scripts/run_pipeline.py wf-sweep --kind beta_mdn --dataset data/H2H2_collisions_numba_b1_0_400000_seed42.npy --tag H2_400000

# Run DSMC experiments for every model in the sweep + plot vs SPARTA
python scripts/run_pipeline.py wf-sweep-eval --kind beta_mdn --tag H2_400000 --sparta data/sparta_H2_energy_relaxationVHS_zinv0151.dat

# Energy-relaxation experiment (model vs BL vs SPARTA)
python scripts/run_pipeline.py relaxation --species H2 --model-kind beta_mdn --model results/models/beta_mdn/H2H2v1.pth --include-bl --sparta data/sparta_H2_energy_relaxationVHS_zinv0151.dat --output results/plots/H2_energy_relaxation.png

# Green-Kubo viscosity
python scripts/run_pipeline.py viscosity --species H2 --model-kind mdn --model results/models/mdn/weightsensitivity/H2_400000_dataseed42/mdn_H2_wf4.pth

# Direct script invocation (legacy, all still work and auto-create dirs)
python training/trainer.py
python training/betamdn_trainer.py
python training/betamdn_wfsweep.py
python visualization/betamdn_wfsweep.py
python experiments/H2_energy_relaxation.py
python experiments/betamdn_H2_energy_relaxation.py
python experiments/O2_energy_relaxation.py
```

There is no test suite. Validation is done via DSMC experiments in `experiments/` and visual comparison in `create_plots.py`.

## Architecture

### Pipeline shape

Almost everything routes through a small set of reusable functions instead of duplicated scripts:

```
        data/*.npy                       (raw CTC datasets, generated by ctc_adjusted/)
            │
            ▼
training.data_prep.load_and_prepare(...)        — (X, y, sample_weights, raw)
            │
            ▼
training.core.train_collision_model(kind, ...)  — dispatches MDN vs BetaMDN
            │
            ▼
        results/models/<kind>/...        (paths.model_path / paths.wf_sweep_model_path)
            │
            ▼
experiments.energy_relaxation.run_relaxation(species, model, ...)
                              .plot_relaxation_comparison(...)
experiments.viscosity.green_kubo_viscosity(stats, ...)
            │
            ▼
        results/plots/...                (paths.plot_path)
```

`paths.py` at the project root is the single source of truth for output locations — every function here calls `paths.ensure_parent(...)` before writing, so missing-directory errors don't happen on fresh clones.

### Data Flow

1. **Data generation**: `ctc_adjusted/ctc_h2_multiple_collisions_numba.py` runs classical trajectory calculations (Lennard-Jones + rigid-rotor H2) to produce collision datasets saved as `.npy` files in `data/`. Each row is `(Etr, Erot_A, Erot_B, Etr', Erot_A', Erot_B')`.

2. **Training**: `training/core.train_collision_model(kind, datapath, outputpath, ...)` is the single entry point. It uses `training/data_prep.py` for dataset normalization and weight construction, then dispatches to either `MixtureDensityNetwork` or `BetaMixtureDensityNetwork`. `training/trainer.py` and `training/betamdn_trainer.py` are thin re-exports.

3. **Inference**: DSMC calls the collision model's `collide()` or `batch_collide()` method per collision pair. `MixtureDensityNetwork`, `BetaMixtureDensityNetwork`, and `borgnakke_larssen_model` all implement this interface.

4. **Validation**: `experiments/energy_relaxation.py` provides `run_relaxation`, `run_relaxation_comparison`, `print_relaxation_table`, and `plot_relaxation_comparison`. The species-specific scripts call them with a `Species` and a model dict. `experiments/viscosity.py` provides `green_kubo_viscosity` used by `H2viscosity.py`.

### Key Modules

**`paths.py`** — Central path helpers (`PROJECT_ROOT`, `DATA_DIR`, `MODELS_DIR`, `PLOTS_DIR`, `model_path()`, `wf_sweep_model_path()`, `plot_path()`, `ensure_parent()`). All output writes go through these.

**`physics/species.py`** — `Species` dataclass + `Species.H2()` / `Species.O2()` factories, holding `mass`, `diameter`, `zrot_bl`, `zrot_mdn`. Experiments take a `Species` instead of inlining constants.

**`physics/dsmc.py`** — Core DSMC simulation engine. Uses Enskog-modified NTC collision selection with Carnahan-Starling EOS pair correlation. Implements cell-based spatial partitioning and vectorized collision pair deduplication (each particle collides ≤1 time per timestep). Tracks stress tensor components (Pxy, Pxz, Pyz) for viscosity.

**`machinelearning/mdn.py`** — Gaussian Mixture Density Network (PyTorch). Takes 3D input `(E_total, η_trans, η_rot_A)` and outputs parameters for K Gaussian mixture components over 2D post-collision energy fractions. Input is z-score normalized; output is also normalized and denormalized at sample time. Methods: `forward`, `sample`, `collide`, `batch_collide`, `save_model`, `load_model`.

**`machinelearning/beta_mdn.py`** — Beta Mixture Density Network (PyTorch). Same interface as MDN but uses Beta distributions instead of Gaussians. Beta is naturally bounded to (0, 1), so output fractions need no clipping. Only input is normalized (output is not, since Beta already lives on [0, 1]). Loss functions `beta_mdn_loss` and `beta_mdn_loss_weighted` are module-level functions.

**`physics/borgnakkelarssen_model.py`** — Physics-based collision baseline. Stochastic model that enforces energy conservation; used as reference in all experiments.

**`machinelearning/gmm.py`** — Sklearn-based GMM; simpler baseline for visual distribution comparison.

**`analysis/kl_divergence.py`** — KDE-based KL divergence utility for comparing distributions.

**`training/data_prep.py`** — Shared collision-dataset preparation (`load_collision_dataset`, `prepare_training_tensors`, `load_and_prepare`).

**`training/core.py`** — `train_collision_model(kind, ...)` plus `train_mdn`/`train_beta_mdn` wrappers.

**`training/wfsweep.py`** — `run_wf_sweep(kind, datapath, tag, weights=...)` trains an entire sweep; `training/betamdn_wfsweep.py` is a 4-line shim that calls it with `kind="beta_mdn"`.

**`experiments/energy_relaxation.py`** — `SimulationParams` dataclass, model loaders (`load_mdn`, `load_beta_mdn`), `run_relaxation`, `run_relaxation_comparison`, `load_sparta_reference`, `print_relaxation_table`, `plot_relaxation_comparison`.

**`experiments/viscosity.py`** — `green_kubo_viscosity(stats, ...)` returns a `ViscosityResult` dataclass; `plot_acf(...)` renders the ACF + cumulative integral.

**`visualization/wfsweep.py`** — `run_wf_sweep_experiments(kind, tag, species, sparta_path)` runs DSMC for every model in a sweep and writes a 3x3 comparison figure. `visualization/betamdn_wfsweep.py` is a thin shim.

**`scripts/run_pipeline.py`** — argparse CLI exposing `train`, `wf-sweep`, `wf-sweep-eval`, `relaxation`, `viscosity` subcommands. Preferred entrypoint for new work.

### Physics Conventions

- Input energy fractions: `η_trans = E_trans / E_total`, `η_rot_A = E_rot_A / (E_rot_A + E_rot_B)`
- Output energy fractions: `η_trans' = E_trans' / E_total`, `η_rot_A' = E_rot_A' / (E_rot_A' + E_rot_B')`
- Total energy is conserved: `E_total_pre = E_total_post` (enforced by construction in `collide()`)
- All collision models operate in the center-of-mass frame
- `zrot` = rotational collision number (Z_rot). For H2: `zrot_bl = 1/0.151`, `zrot_mdn = zrot_bl / 3.5`. `Species` defaults encode this — experiments should pass `species.zrot_bl` or `species.zrot_mdn` automatically via `run_relaxation`.

### Weighting Factor (`wf`)

Training samples are weighted by `E_trans^wf` to up-weight high-energy collisions (more physically relevant under NTC collision selection). The sweep `wf ∈ [0.25, 0.5, 1, 2, 3, 4, 5, 6, 7]` is the main hyperparameter study. Models are saved with the `wf` value encoded in the filename (e.g. `beta_mdn_H2_wf4.pth`) via `paths.wf_sweep_model_path`.

### Output Paths

`paths.py` produces:

```
results/models/mdn/weightsensitivity/<tag>/    # Gaussian MDN models (paths.wf_sweep_model_path)
results/models/beta_mdn/weightsensitivity/<tag>/  # Beta MDN models
results/models/beta_mdn/H2H2v1.pth             # single trained Beta MDN (paths.model_path)
results/plots/                                  # experiment figures (paths.plot_path)
```

Directories are created on the fly — fresh clones don't need pre-existing `results/`.

### Configuration

- `config/experiment_config.py`: MDN hyperparams — `lr=2e-4`, `batch_size=256`, `num_epochs=200`, `hidden_dim=128`, `num_mixtures=5`, `trainval_split=0.7`, `random_seed=42`
- `config/plotting_config.py`: Figure styling defaults
